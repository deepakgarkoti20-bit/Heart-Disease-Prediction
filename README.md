❤️ Heart Disease Prediction using Machine Learning

📌 Project Overview

This project is a Machine Learning-based Heart Disease Prediction system that predicts whether a person is likely to have heart disease based on selected medical attributes.

The project uses a Logistic Regression machine learning algorithm to perform binary classification.

🎯 Objective

The main objective of this project is to understand how Machine Learning can be applied to healthcare-related datasets for classification and prediction.

🧠 Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab
- Jupyter Notebook

📊 Dataset

The project uses a heart disease dataset containing 1025 records and 14 columns.

The dataset includes features such as:

- Age
- Sex
- Chest Pain Type (CP)
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- Slope
- Number of Major Vessels (CA)
- Thalassemia (Thal)
- Target

The target column represents the prediction class.

⚙️ Machine Learning Model

The project uses Logistic Regression for classification.

The dataset is divided into training and testing sets using "train_test_split", and the model's performance is evaluated using accuracy score.

🔄 Project Workflow

1. Import the required libraries.
2. Load the heart disease dataset.
3. Explore and prepare the data.
4. Separate features and target.
5. Split the dataset into training and testing data.
6. Train the Logistic Regression model.
7. Make predictions on test data.
8. Calculate the model accuracy.
9. Test the model with new input values.

🔮 Prediction

The trained model can take selected input features and predict whether the input corresponds to the presence or absence of heart disease according to the dataset's target classes.

Input: Patient-related feature values
Output: Predicted class
